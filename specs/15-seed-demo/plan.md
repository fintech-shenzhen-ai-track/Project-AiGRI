# 15 Seed and demo: plan

`seed/`, `backend/aigri/core/seed_loader.py`, `scripts/demo/`.

## Layout

```
seed/
  fixtures/
    insurers.yaml        4 insurers, status and dates (PLAN 2.1, 2.12)
    people.yaml          staff, superadmin, client contacts (PLAN 2.4, 2.3)
    clients.yaml         C1, C2, C3 + queue-only clients (PLAN 2.3, 2.9)
    parcels.geojson      generated by tools/make_parcels.py, committed
    livestock.yaml       Pak Slamet's group and 12 tags (PLAN 2.3)
    records/*.yaml       8 compiled Policy Record bodies (expected compiler outputs, for golden tests)
    risk/*.yaml          calibrated risk outputs (FR-15.7)
    forecasts.yaml       rain series (PLAN 2.2, 2.3)
    events.yaml          Central Java floods, Feb 2026 (PLAN 2.2)
    damage/*.yaml        fixture Damage Assessments (PLAN 2.8) and cattle checks
    claims.yaml          detailed claims (PLAN 2.8, 2.9) + generator parameters
    wallets.yaml         opening balances and funding (PLAN 2.3, 2.10)
    nudges.yaml, disputes.yaml (PLAN 2.12)
  policies/*.md          clause templates → PDFs
  photos/                generator + metadata (PLAN 2.8 chips)
  tools/
    make_parcels.py      polygons from centroids and hectares
    make_pdfs.py         Markdown → PDF (permissive library, e.g. ReportLab), hidden-text injection for ACA
    make_photos.py       procedural images + pHash distance assertion
    calibrate_risk.py    solve class probabilities for FR-15.7
scripts/demo/
  story.py               the timeline, step functions, checkpoints
  checkpoint.py          dump and restore (pg_dump/pg_restore + MinIO mirror)
  background.py          deterministic bulk generator (FR-15.6)
```
